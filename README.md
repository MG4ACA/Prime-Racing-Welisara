# Prime Racing Welisara 🏍️

A stunning, animation-rich portfolio website for Prime Racing Welisara - premium motorcycle dealership featuring KTM, Kawasaki, Yamaha, and Triumph.

## 🚀 Tech Stack

- **Vue 3** (Composition API)
- **Tailwind CSS** (Dark Mode)
- **GSAP** (Advanced animations & ScrollTrigger)
- **Lucide Vue Next** (Beautiful icons)
- **Vite** (Lightning-fast build tool)

## 📦 Installation

```bash
npm install
```

## 🏃 Development

```bash
npm run dev
```

Visit http://localhost:3000

## 🏗️ Build

```bash
npm run build
```

## ✨ Features

- 🎨 Rich UI with dark mode and KTM Orange accents
- 🎭 Advanced GSAP animations (letter-by-letter reveals, parallax effects)
- 📱 Fully responsive design
- 🏍️ Inventory grid with 5 featured motorcycles
- 📝 Test ride booking form
- 💬 WhatsApp floating action button
- 🗺️ Contact information and business hours
